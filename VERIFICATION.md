### Границы проверки

Новая внешняя база не подключалась. Вход с реальным пользователем, сохранение игры и полный сценарий PDF через авторизованные API на внешней базе не проверялись. Проверен сам локальный PDF-рендерер и отсутствие доступа к закрытым API без сессии. Развёртывание в аккаунте Vercel и загрузка в GitHub не выполнялись.

Установка сообщает предупреждения о peerDependencies у части сохранённых UI-библиотек (React, React DOM, типы React, date-fns). Они не помешали проверке типов и сборке. Полный аудит совместимости всех неиспользуемых UI-компонентов не проводился. Отдельный `yarn lint` не запускался; успешная сборка не означает отсутствие lint-предупреждений.

Проверка архива при упаковке сопоставляет содержимое с секретами исходного окружения, исключает служебные каталоги и проверяет контрольные суммы оригинальных изображений. Итог упаковки записан в `ARCHIVE_CHECK.json`. `SHA256SUMS.txt` содержит хеши файлов до упаковки.
